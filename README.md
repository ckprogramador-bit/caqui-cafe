# Caqui Café

Site estático em português para apresentar o cardápio, as cestas e a localização do Caqui Café em Rio do Sul - SC.

## Prévia local

Abra `index.html` em um navegador. Fontes, fotos, mapa e links do WhatsApp usam serviços externos e precisam de conexão com a internet.

## Publicar no GitHub

1. No VS Code, abra **Controle do Código-Fonte** e escolha **Inicializar Repositório**.
2. Revise as alterações e faça o primeiro commit.
3. Use **Publicar Branch** para criar ou selecionar um repositório no GitHub.

## Publicar na Vercel

1. Importe o repositório GitHub na Vercel.
2. Selecione **Other** como framework preset. Não é necessário comando de build; mantenha `index.html` na raiz e use `.` como diretório de saída se a Vercel solicitar.
3. Faça o deploy. Para atualizações futuras, envie os commits ao GitHub e a Vercel fará novo deploy automaticamente.

Não há dependências ou variáveis de ambiente necessárias. O telefone e os links usados no site são os fornecidos no HTML original.
